# Code of Conduct

SchedForge follows the Contributor Covenant Code of Conduct, version 2.1.

## Our Standards

Contributors should use welcoming and inclusive language, respect differing
technical viewpoints, provide constructive feedback, and focus discussions on
the code, evidence, and documented claim boundaries.

Harassment, discrimination, personal attacks, doxxing, and other abusive
behavior are not acceptable in project spaces.

## Enforcement

Report unacceptable behavior privately to the repository owner through the
contact method listed on the owner's GitHub profile. Reports will be reviewed
confidentially and handled in proportion to the circumstances.

The full Contributor Covenant text is available at:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/
